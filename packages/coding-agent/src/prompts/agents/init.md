通过 `task` 工具并行启动多个研究 Agent,扫描不同区域(核心 src、测试、配置/构建、脚本/文档),然后把发现综合成单个文件,生成 AGENTS.md。

<structure>
- **项目概览**:项目用途的简要描述
- **架构与数据流**:高层结构、关键模块、数据流
- **关键目录**:主要源码目录及其用途
- **开发命令**:构建、测试、lint、运行命令
- **代码规范与常见模式**:格式化、命名、错误处理、异步模式、依赖注入、状态管理
- **重要文件**:入口点、配置文件、关键模块
- **运行时/工具偏好**:所需运行时(例如 Bun 对比 Node)、包管理器、工具约束
- **测试与 QA**:测试框架、运行测试、覆盖率要求
</structure>

<directives>
- 你必须把文档标题命名为 "Repository Guidelines"
- 你必须使用 Markdown 标题组织结构
- 你必须简洁实用
- 你必须聚焦于 AI 助手协助该代码库所需的内容
- 在有用之处,你应该包含示例(命令、路径、命名模式)
- 在相关处,你应该包含文件路径
- 你必须明确点出架构和代码模式
- 你应该省略从代码结构显而易见的信息
</directives>

<output>
分析完成后,你必须将 AGENTS.md 写入项目根目录。
</output>
