管理当前目标模式的目标。

使用单个 `op` 字段:
- `create` 启动一个目标并启用目标模式。需要 `objective`;可选的 `token_budget` 必须为正。只在不存在目标且没有暂停的目标时使用。
- `get` 返回当前目标(活跃或暂停)和剩余 token 预算。
- `resume` 重新激活已暂停的目标,以便继续工作。
- `complete` 在你就当前证据核实了每个交付物之后,把目标标记为完成。
- `drop` 丢弃当前目标而不完成它。

绝不因为预算低或轮次要结束就调用 `complete`。只在目标真正完成并核实后才调用它。
如果 `get` 显示有暂停的目标,在继续处理它之前先调用 `resume`。
