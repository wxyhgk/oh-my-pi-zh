规划、启动、检查、取消和验证 OMP 原生的仓库安全扫描。`preflight` 创建一份不可变计划,固定到仓库快照、模型和确切的 OAuth 凭据。`start` 把计划作为后台 OMP 作业运行。`status` 和 `cancel` 使用返回的操作 ID。`cloud_scans` 列出所选 ChatGPT OAuth 账户的 Codex Security 云配置。`cloud_start` 使用 `repository_id`、`repository_url` 和 `environment_id` 创建并启用云扫描配置;这会消耗账户单独的 Codex Security 云额度,绝不作为原生扫描的回退。`cloud_status` 读取云进度。`cloud_pull` 把云发现导入规范 OMP 安全存储,在那里可通过 `security://` 访问。云操作使用 `cloud_configuration_id`,可以用 `credential_id` 固定账户。必须在设置中启用安全功能。
