启动一个持久 worker 会话——一个你通过对话驱动的完整编码 Agent(edit、bash、grep,什么都有)。按任务选择 CLI 口味:

- `fast`:低延迟模型,用于机械、定义良好的工作(重命名、样板、运行测试、数据收集)。
- `good`:强模型,用于困难工作(设计、调试、多文件变更、判断调用)。

`prompt` 是会话的第一条指令。worker 除了它没有任何上下文——包含文件、约束和验收标准。`name`(可选)给会话命名;否则自动生成一个。

立即返回会话 id;轮次的结果(活动轨迹 + worker 的回复)会在 worker 完成时自动交付给你。除非被阻塞,不要等待——继续指挥其他会话。

轮次结束后会话仍然持久:它记得整个对话。用 `vibe_send` 继续它;绝不为同一工作流的后续问题生成第二个会话。
