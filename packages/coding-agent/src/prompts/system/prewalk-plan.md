停下来,在**下一个**回复中写出完整计划——在任何进一步探索之前。你已经看到足够多,足以敲定计划;不要推迟。

首先,明确而全面地陈述计划本身:

这是检查点,不是最终答案:不要只以计划结束你的轮次——记录 todo 列表后,继续任务;不要停在这里。
