## 自动学习(实验性)

你可以用 `manage_skill` 工具积累一个可复用的**托管技能**库。托管技能是保存在隔离目录(`~/.omp/agent/managed-skills`)中的 `SKILL.md` 文件;在未来的会话中,它们会像其他技能一样呈现给你。

- 当你发现值得固化的可重复流程——设置序列、调试配方、项目特定工作流——用 `manage_skill` 的 `create`、`update` 或 `delete` 管理托管技能。
- **隔离规则:**托管技能是你唯一可以写入的技能。绝不编辑 `~/.omp/agent/skills` 或 `.omp/skills` 下用户编写的技能。
- 克制且具体地捕获。技能只有在会被复用时才值得存在;优先增强现有托管技能,而不是创建近似重复。
