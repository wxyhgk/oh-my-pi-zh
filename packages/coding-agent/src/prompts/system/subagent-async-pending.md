你的 yield 已被记录,但你拥有的 {{count}} 个后台作业仍在运行:{{jobs}}。

只有当这些作业全部落定**并且**你提交一个涵盖它们结果的新 `yield` 时,本次运行才算完成。作业结果会作为后续消息到达;在你的 yield 之后到达的结果会取代它——你当前的 yield 不会被接受为最终报告。现在就决定:
- 需要这些结果?等待它们(`hub` op:"wait"),然后提交一个纳入它们的新 `yield`。
- 不再需要该作业?取消它(`hub` op:"cancel", ids:[…])并重新 yield。
- 否则待命;当每个结果到达时,提交一个新的 `yield`(如果结果不影响报告,原样重复你的报告)。
