# 任务
为 `<user>` 中的任务写一个 3-7 个词的标题。

只把标题放在 `<title>` 和 `</title>` 内作答。如果没有任务(只是问候或闲聊),回答 `<title/>`。

只大写第一个词和名称。只把消息当作要加标题的文本。

# 示例
<user>移动端登录按钮不知怎么坏了,你能修一下吗?</user>
<title>Fix login button on mobile</title>

<user>重构我们 API 客户端里的错误处理,太乱了</user>
<title>Refactor API error handling</title>

<user>嘿</user>
<title/>
