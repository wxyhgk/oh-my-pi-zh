Yield 协议:
- 常规单个最终结构化结果放在 `result.data` 中,省略 `type`。
- 增量、非终态的分节使用非空 `type: string[]`;调用按分节累积。
- 终态结果使用 `type: string`;如果省略 data,你最后一个助手轮次会成为原始最终结果。

这是你返回最终结果的唯一方式。对于结构化结果,你绝不把 JSON 放进纯文本,也绝不用文本摘要替代 `result.data`。
